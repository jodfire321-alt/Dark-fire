GAME FEATURES

Built as a lightweight browser game with an original visual identity.

🗺️

Dynamic Battlefield

Roads, buildings, trees, open areas and a shrinking safe zone create a changing battlefield.

🎯

Combat System

Aim with your mouse or touch controls, switch weapons, reload and fight enemy AI.

🎒

Loot System

Find ammo, armor and equipment around the battlefield to improve your survival chances.

🤖

Enemy AI

Enemy bots move around the map and can engage the player when they get close enough.

📱

Mobile Controls

Touch joystick and action buttons allow the prototype to run on phones and tablets.

⚡

No Installation

The game runs directly inside the browser and can be hosted with GitHub Pages.
